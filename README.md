## 🐳 Configuration Docker (DS2)

Ce projet a été industrialisé avec Docker et Docker Compose. 
**Prérequis :** Docker Desktop (Version 24.0+ ou ultérieure) doit être installé et en cours d'exécution.

**Comment lancer le projet localement :**
1. Clonez ce dépôt.
2. Ouvrez un terminal à la racine du projet.
3. Exécutez la commande : `docker-compose up -d`
4. Le site web (Frontend) sera disponible sur : `http://localhost:8080`
5. L'API (Backend Mock) sera disponible sur : `http://localhost:8085`
